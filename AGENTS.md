# AGENTS.md

Instructions for coding agents working in this repo. Start with
[docs/README.md](docs/README.md): it has the pitch, a reading order and a map
of where each topic lives.

## Working rules

- **Verification bar before any push.** The server suite in docker
  (`docker build -f server/Dockerfile.test -t inky-almanac-test server &&
  docker run --rm inky-almanac-test`) and the frame suite
  (`mise run frame-test`) both pass. Every behaviour fix has a test that was
  seen to fail with the fix reverted. If a change touches the layout,
  regenerate the stills (`docs/development.md`, "Previewing posters") and
  look at them. PR test plans say what was actually run, and what could not
  be verified (usually: on the real frame).
- **Secret-scan before every push.** Check the diff and commit messages
  against every value in the gitignored `server.env`, `deploy.env` and
  `frame/config.py`, reading the values from the files and never printing
  them or putting them in a command line. Also grep for private IPs,
  coordinates other than central Sydney or Observatory Hill, emails and the
  configured town's name.
- **Never commit real configuration.** The location, hosts, Wi-Fi details
  and the OTA key live only in gitignored files (`server.env`, `deploy.env`,
  `frame/config.py`, `WIFI_CONFIG.py`, `OTA_KEY.py`). Tests, fixtures and
  stills use central Sydney.
- **Merge only on the operator's word.** Green CI and a finished review are
  not a go-ahead. This repo merges with merge commits.
- **Don't re-sign OTA for unchanged frame code.** Every signed release makes
  the frame download, reboot and redraw. Deploy server-only changes with
  `OTA_KEY_FILE=` (empty). Deploys and OTA releases need the operator's
  go-ahead.
- **Don't edit `docs/img`.** It is generated by
  `server/tests/render_stills.py`.
- **Keep `docs/design.md` true.** If you change a behaviour it describes,
  update the note and say why; add new traps to `docs/gotchas.md`.
- **Treat a delegated report as a claim.** Verify it against the diff, the
  code or a command before relaying it.
